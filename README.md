# 세종 봉쇄구역

가상의 양지고등학교에서 시작하는 1~4인 웹 협동 좀비 생존 게임입니다. PC 키보드와 스마트폰 가로 터치를 같은 방에서 사용합니다. 현재 플레이 가능한 콘텐츠는 **에피소드 0 — 탈출 불가능한 학교**의 교실 → 동관 → 운동장입니다. 에피소드 1~4는 기획 데이터만 있으며 선택할 수 없습니다.

## 개발 실행

Node.js 22.12 이상과 npm이 필요합니다. 테스트 검증 환경은 Node 24.19.0, Phaser 4.2.1, Wrangler 4.151.0입니다. 로컬 실행에는 Cloudflare 계정이나 토큰이 필요 없습니다.

```bash
cd /workspace/yangjigo
export npm_config_cache=/tmp/sejong-npm-cache
export XDG_CONFIG_HOME=/tmp/sejong-config
export WRANGLER_SEND_METRICS=false
npm ci --no-audit --no-fund
npm run db:migrate
npm run dev
```

서버는 8787 포트에서 정적 파일, API, WebSocket, 로컬 D1과 Durable Objects를 함께 실행합니다. 클라이언트 수정 후 `npm run build`로 다시 빌드합니다. 서버 코드는 Wrangler가 감시합니다. `.wrangler`는 로컬 계정과 방 저장소이므로 임의로 삭제하지 마세요. 소스 백업에는 이 데이터가 포함되지 않습니다.

회원가입 → 채널 선택 → 방 생성/참가 → 직업/난이도 선택 → 전원 준비 → 방장 시작 순서입니다. 비공개방은 방 ID와 초대 코드로 참가합니다. 스마트폰 세로 화면에서는 로그인·상점·플레이를 포함한 모든 조작이 차단됩니다.

## 조작

| 기능      | PC                          | 터치                   |
| --------- | --------------------------- | ---------------------- |
| 이동      | WASD / 방향키               | 왼쪽 조이스틱          |
| 기본 공격 | J (길게 누르기 가능)        | 공격 버튼              |
| 스킬      | K / L                       | 스킬 1 / 2             |
| 상호작용  | E                           | 상호작용 버튼          |
| 작업대    | U (작업대 옆에서 강화 가능) | 작업대 옆에서 상호작용 |
| 메뉴      | ESC                         | 메뉴 버튼              |

메뉴·NPC 대화는 본인의 입력만 멈춥니다. 멀티플레이는 계속 진행됩니다. 전원이 연결을 잃으면 시뮬레이션을 멈추고 방어 임무의 남은 시간을 보존합니다.

## 에피소드와 난이도

| 난이도 | 완주 XP / 재화 | 입장 조건                     | 완주 티켓                  |
| ------ | -------------- | ----------------------------- | -------------------------- |
| 이지   | 180 / 90 C     | 없음                          | 없음                       |
| 노말   | 300 / 150 C    | 없음                          | 해당 에피소드 하드 티켓 +1 |
| 하드   | 450 / 225 C    | 전원이 해당 에피소드 티켓 1장 | 없음                       |

기본 정책은 **하드 입장 때 각자 1장을 소모**하는 방식입니다. 체크포인트 재도전·같은 방에서 처음부터 재시작은 추가 소모하지 않습니다. 새 방의 새 하드 입장에는 다시 필요합니다. 한 명이라도 부족하면 전원 차감 없이 입장이 거부됩니다. 다른 에피소드 티켓으로 대체할 수 없습니다. 난이도 변경은 전원의 준비 상태를 해제합니다.

상점의 생존자(75 C)·탐험가(150 C)·구조대(300 C) 스킨은 실제 클리어 재화로 구매합니다. 기본 교복은 무료 지급입니다. 장착은 다음 방 참가부터 적용되고 능력치는 바뀌지 않습니다. 구매·보상·티켓은 서버 DB에서 검증합니다.

## 검사

```bash
npm run build
npm test
npm run test:e2e
```

SQLite 테스트에는 Python 3, 브라우저 테스트에는 Chromium이 필요합니다. `/usr/bin/chromium`이 있으면 자동 사용하며 다른 설치 경로는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`로 지정합니다. 없으면 `npx playwright install chromium`으로 설치합니다. E2E는 8788 포트와 임시 D1/DO 저장소를 사용하고 종료 시 정리합니다. 개발 계정이나 DB는 사용하지 않습니다.
