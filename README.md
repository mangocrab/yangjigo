# 세종 봉쇄구역

가상의 양지고등학교에서 시작하는 1~4인 웹 협동 좀비 생존 게임입니다. PC 키보드와 스마트폰 가로 터치를 같은 방에서 사용합니다. 현재 플레이 가능한 콘텐츠는 **에피소드 0 — 탈출 불가능한 학교**의 교실 → 동관 → 운동장입니다. 에피소드 1~4는 기획 데이터만 있으며 선택할 수 없습니다.

## 개발 실행

Node.js 22.12 이상과 npm이 필요합니다. 테스트 검증 환경은 Node 24.19.0, Phaser 4.2.1, Wrangler 4.151.0입니다. 로컬 실행에는 Cloudflare 계정이나 토큰이 필요 없습니다.

```bash
cd /workspace/yangjigo
export npm_config_cache=/tmp/sejong-npm-cache
export XDG_CONFIG_HOME=/tmp/sejong-config
export WRANGLER_SEND_METRICS=false
npm ci --no-audit --no-fund
npm run db:migrate
npm run dev
```

서버는 8787 포트에서 정적 파일, API, WebSocket, 로컬 D1과 Durable Objects를 함께 실행합니다. 클라이언트 수정 후 `npm run build`로 다시 빌드합니다. 서버 코드는 Wrangler가 감시합니다. `.wrangler`는 로컬 계정과 방 저장소이므로 임의로 삭제하지 마세요. 소스 백업에는 이 데이터가 포함되지 않습니다.

회원가입 → 채널 선택 → 방 생성/참가 → 직업/난이도 선택 → 전원 준비 → 방장 시작 순서입니다. 비공개방은 방 ID와 초대 코드로 참가합니다. 스마트폰 세로 화면에서는 로그인·상점·플레이를 포함한 모든 조작이 차단됩니다.

## 조작

| 기능      | PC                   | 터치               |
| --------- | -------------------- | ------------------ |
| 이동      | WASD / 방향키        | 왼쪽 조이스틱      |
| 기본 공격 | J (길게 누르기 가능) | 공격 버튼          |
| 스킬      | K / L                | 스킬 1 / 2         |
| 상호작용  | E                    | 상호작용 버튼      |
| 무기 획득 | 비상 장비함 옆에서 E | 장비함 옆 상호작용 |
| 메뉴      | ESC                  | 메뉴 버튼          |

구간 컷신은 전원이 장면을 확인할 때까지 이동·공격·적 AI를 함께 멈춥니다. 평상시 메뉴·NPC 대화는 본인의 입력만 멈춥니다. 멀티플레이는 계속 진행됩니다. 전원이 연결을 잃으면 시뮬레이션을 멈추고 방어 임무의 남은 시간을 보존합니다.

## 에피소드 0: 직업을 얻는 첫날

방에서 **한도윤(선봉대)**, **백해인(의무대)**, **강시우(수색대)**, **윤태오(공작대)** 중 선택합니다. 4인 방에서는 직업이 중복되지 않습니다. 새 참가자는 빈 직업을 배정받고 다른 동료가 고른 직업은 잠깁니다. 연결이 끊겨도 퇴장/유예 만료 전에는 해당 직업을 예약합니다. 직업에 맞는 독립 도트 캐릭터와 무기가 표시됩니다. 시작할 때는 모두 무기 없이 돌을 던집니다. 이동·상호작용을 익히고, 돌을 적에게 세 번 맞힌 뒤 퓨즈와 비상 장비함을 찾아 **배트/구조용 신호총/활/전기봉**을 얻어야 직업 스킬이 열립니다. 전원이 개별적으로 장비를 받아야 진행합니다.

에피소드 0에는 작업대가 없습니다. 시작, 무기 획득, 교실→동관, 동관→운동장, 마지막 탈출에 도트 배경·주연 초상화·다중 대사 컷신이 나옵니다. 각자 끝까지 확인한 후 함께 재개하며, 종료한 플레이어는 확인하지 않은 동료를 기다립니다. 연결이 끊긴 참가자는 확인 대기를 막지 않습니다.

수색대는 장거리 집중 사격과 6초 공격 속도 강화, 공작대는 벽을 넘지 않는 근거리 전류·기절과 동료 방벽을 사용합니다. 모든 스킬은 서버에서 판정합니다.

감염자는 교복(기본 추격), 체육복(낮은 HP·빠른 접근), 시설관리자(높은 HP·강한 타격·느린 이동) 3종입니다. 원본 32×32 픽셀 캐릭터, 방향/걷기 프레임, 교실 소품, 무기 이펙트와 컷신 배경은 직접 제작했습니다.

SPACE / 반격 버튼은 적이 공격 타일을 예고할 때 정면에서 사용합니다. 성공하면 2초간 적을 멈추고 받는 피해를 2배로 만듭니다. 모든 판정은 서버가 처리합니다.

## 에피소드와 난이도

| 난이도 | 완주 XP / 재화 | 입장 조건                     | 완주 티켓                  |
| ------ | -------------- | ----------------------------- | -------------------------- |
| 이지   | 180 / 90 C     | 없음                          | 없음                       |
| 노말   | 300 / 150 C    | 없음                          | 해당 에피소드 하드 티켓 +1 |
| 하드   | 450 / 225 C    | 전원이 해당 에피소드 티켓 1장 | 없음                       |

기본 정책은 **하드 입장 때 각자 1장을 소모**하는 방식입니다. 체크포인트 재도전·같은 방에서 처음부터 재시작은 추가 소모하지 않습니다. 새 방의 새 하드 입장에는 다시 필요합니다. 한 명이라도 부족하면 전원 차감 없이 입장이 거부됩니다. 다른 에피소드 티켓으로 대체할 수 없습니다. 난이도 변경은 전원의 준비 상태를 해제합니다.

상점의 생존자(75 C)·탐험가(150 C)·구조대(300 C) 스킨은 실제 클리어 재화로 구매합니다. 기본 교복은 무료 지급입니다. 장착은 다음 방 참가부터 적용되고 능력치는 바뀌지 않습니다. 구매·보상·티켓은 서버 DB에서 검증합니다.

## 검사

```bash
npm run build
npm test
npm run test:e2e
```

SQLite 테스트에는 Python 3, 브라우저 테스트에는 Chromium이 필요합니다. `/usr/bin/chromium`이 있으면 자동 사용하며 다른 설치 경로는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`로 지정합니다. 없으면 `npx playwright install chromium`으로 설치합니다. E2E는 8788 포트와 임시 D1/DO 저장소를 사용하고 종료 시 정리합니다. 개발 계정이나 DB는 사용하지 않습니다.

[현재 진행 상황](docs/PROGRESS.md), [설계](docs/GAME_DESIGN.md), [아키텍처](docs/ARCHITECTURE.md), [배포](docs/DEPLOYMENT.md), [장애 원인과 복구](docs/ENVIRONMENT_RECOVERY.md)를 참고하세요. [최초 요구사항](docs/REQUIREMENTS.md)보다 이후 대화의 에피소드 번호·난이도·티켓 지시가 우선합니다.

## 외부 참고 자료 확인 상태

클래식·디비전 본문과 실제 하위 문서 4개에 접근해 에피소드 0의 이야기/플레이 교대와 디비전의 상호작용·구조·공격 예고·카운터를 참고했습니다. 전원 장치는 E로 시작한 뒤 1.5초 유지하며 이동·공격·피격 시 취소됩니다. 동료 구조는 4초가 필요합니다. 무기 획득 후 SPACE 또는 반격 버튼으로 정면의 공격 예고를 끊을 수 있습니다.

컷신은 전체 화면 배경과 하단 대화창, 순차 대사, 이전 대사·대화 기록을 제공합니다. 텍스트가 나오는 중에는 다음 버튼/Enter를 누르면 전체 대사를 표시하고, 다시 누르면 다음 대사로 넘어갑니다. 전원 확인 후 목표 안내와 플레이로 복귀합니다.

YouTube 영상은 여전히 실제 재생하지 못했으므로 해당 영상과 UI를 대조한 상태는 아닙니다. [참고 자료 검토 기록](docs/REFERENCE_REVIEW.md)에 읽은 범위·적용한 요소·재생 실패와 남은 확인을 구분했습니다.
