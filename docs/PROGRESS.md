# 개발 진행 기록

2026-10-21 · v0.4.0 · Phase 3 스토리 개선, Phase 4 일부 구현.

## 이번 요청 반영

- 32×32 원본 도트 캐릭터와 4방향·걷기 2프레임, 의상별 외형. 교실의 창·벽·책상·노트·돌무더기·비상 장비함 등 픽셀 소품과 무기별 이펙트를 보강했다.
- 방에서 주연과 직업을 선택한다. 한도윤(야구부·선봉대)은 머리띠와 배트, 백해인(보건 동아리·의무대)은 묶은 머리·응급 가방·구조용 신호총을 사용한다. 방의 미리보기와 실제 플레이가 같은 캐릭터를 표시한다. 중복 선택을 허용하고 게임 중 변경은 거부한다.
- 에피소드 0은 감염 직후 시작 → 이동·상호작용 → 돌 던지기 실제 적중 → 퓨즈 → 전원 개별 무기 수령 → 직업 스킬 해금 → 잠금장치 → 동관 → 운동장 탈출의 흐름이다. 무기 전에는 스킬 사용을 서버가 거부한다.
- 에피소드 0의 세 맵에서 작업대를 제거했다. 강화 UI 진입과 직접 서버 명령도 차단한다. 향후 에피소드용 로직만 남겼다.
- 감염자는 교복·체육복·시설관리자 3종이다. 외형뿐 아니라 HP·추격/공격 간격·피해·탐지 거리를 다르게 적용한다.
- 시작·무기 획득·교실→동관·동관→운동장·엔딩의 5개 컷신을 도트 배경·주연 초상화·다중 대사로 제작했다. 전원이 확인할 때까지 이동·공격·적 AI가 멈추고, 이전 장면 ID·중복 확인·ESC 우회를 차단한다. 끊긴 참가자는 대기를 막지 않는다. 개인 NPC 대화·메뉴는 방 전체를 멈추지 않는다.
- 무기·돌 적중 상태를 체크포인트와 DO에 보존한다. 이전 v2/v3 방은 기존 무기와 퍼즐 미션 진행을 보존해 변환한다. 기존 D1 데이터는 변경하지 않는다.

## 유지한 기능

실제 D1 가입/로그인/세션, 논리적 2채널, 공개/비공개 4인 방, 방장 이전·재접속, 서버 격자/전투/AI, 스마트폰 가로 전용·독립 멀티터치, 에피소드별 이지/노말/하드·보상·티켓, 실제 재화 상점·소유권·장착·프로필·업적을 유지한다. 노말 완주마다 같은 에피소드 하드 티켓 1장, 하드 입장 시 전원 1장 소모, 같은 입장 재도전은 무료다.

## 검사

- `npm run build`: 클라이언트·서버 타입 검사와 Vite 빌드 통과.
- `npm test`: 2개 파일 **28개 통과**. 컷신 중 서버 행동 정지·전원 확인·중복/이전 ID·연결 종료, 실제 돌 적중·무기별 해금·작업대 거부·기존 방 변환·체크포인트·감염자 수치와 기존 SQLite 거래/티켓 검사를 포함한다.
- `npm run test:e2e`: Chromium 통합 시나리오 **3개 통과**, 약 2분 6초. PC/모바일 4인 노말·하드 완주, 티켓·구매·프로필, 멀티터치·세로 차단, 주연 선택·돌 던지기·무기 획득·5개 컷신 전환·실제 퍼즐·체크포인트를 검사했다. 모바일 컷신의 하단 구도 조정 후 해당 모바일 검사도 추가 실행해 통과했다.

실제 로컬 Worker·D1·DO·WebSocket과 Chromium을 사용한다. E2E는 독립 임시 DB를 만들고 개발 DB는 사용하지 않는다. 화면 캡처는 `docs/screenshots`에 보존한다. 저장된 클라우드 시작 지침도 새 에피소드 0 규칙에 맞게 갱신했다. 초안 저장은 환경 Publish와 다르다.

## 남은 기능과 한계

- 에피소드 1~4는 기획 데이터만 있다. 추가 맵·보스·직업·사운드·더 풍부한 연출은 후속 작업이다.
- 추가 강화는 이후 에피소드에서 도입한다. 에피소드 0에는 도입하지 않는다.
- 자유 터치 버튼 배치·유동 조이스틱·진동·저사양 품질 설정, 실제 채널 접속 인원/혼잡도 모니터링은 미완료다.
- iPhone Safari/Android 실기기·Firefox·Safari, 공개 Cloudflare 배포·동시접속 부하·비용 측정은 미검증이다.
- Phaser를 포함한 큰 JS 청크 경고가 남아 있다. 초기 로딩 최적화가 필요하다.
- 2026-10-21 사용자 요청에 따라 게임 구현 커밋 `8d6824e`를 `mangocrab/yangjigo`의 원격 `main`에 푸시하고 SHA 일치를 확인했다. 환경 Publish·새 작업 복원 검증은 별도다. 소스 백업에 DB·세션·비밀값은 포함하지 않는다. 이전 환경 장애와 소스 누락 기록은 `ENVIRONMENT_RECOVERY.md`에 남겼다.
