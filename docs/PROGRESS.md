- 실제 클리어 재화 상점, 구매 확인·중복 차감 방지, 4종 독립 외형·서버 소유권 검증·장착·게임 반영.

## 이번 장애와 수정

실행 환경 초기화 실패 후 현재 셸·Worker 실행이 복구됐다. 작업 공간과 원격에 이전 소스가 없어 대화와 첨부 요구사항에서 소스를 다시 작성했다. 이전 계정 DB는 복구되지 않았다. 상세 원인 구분과 예방은 `ENVIRONMENT_RECOVERY.md`에 기록한다.

대기실 스냅샷 갱신으로 오류 메시지가 사라지던 문제를 고쳤다. 세션은 유효하지만 이전 방이 사라진 경우에는 로그인 화면으로 보내는 대신 채널 선택으로 복귀한다. 인증의 비동기 실패를 Worker 오류 처리에서 기다리도록 고쳐 잘못된 비밀번호·중복 가입에도 정상 JSON 오류를 반환한다. 브라우저 테스트의 canvas 선택자는 게임 영역을 지정해 대기실 스킨 미리보기와 구분한다.

## 검사

최종 실행 결과:

- `bash scripts/setup.sh`: frozen-lockfile 설치, 마이그레이션 반복 적용, 빌드, 테스트 성공.
- `npm run build`: 클라이언트/서버 TypeScript 검사와 Vite 빌드 성공.
- `npm test`: 2개 파일, 단위·SQLite 경제/마이그레이션 검사 **19개 통과**.
- `npm run test:e2e`: Chromium 브라우저 시나리오 **3개 통과**, 약 1분 48초. 4인 노말/하드 완주, 입장 거부 시 무차감·전원 차감·중복 차감 방지, 구매/장착/프로필, 로그인 실패/중복 가입, 키보드/멀티터치/회전, 퍼즐/작업대/게임오버/체크포인트 복원을 포함한다.
- `npm run dev`: 8787 포트 로컬 서버 실행, 루트 HTML 200 및 비인증 `/api/me` 401 확인.
- 클라우드 환경 설치/시작 지침 초안 저장 확인(`requires_publish=true`). Publish·새 작업 복원은 미검증.

 빌드는 클라이언트/서버 TypeScript 검사와 Vite 번들 생성을 포함한다. 브라우저 테스트는 실제 로컬 Worker·WebSocket·D1/DO·Chromium을 사용하며, 4개 계정의 노말/하드 완주와 경제 API, 모바일 입력, 퍼즐 UI·체크포인트를 검사한다. 테스트용 임시 계정과 DB는 개발 DB와 분리한다.
