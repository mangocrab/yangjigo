YouTube watch 페이지와 공식 oEmbed도 같은 403으로 실패했다. 이는 내용을 읽고 분석한 결과가 아니라 네트워크 접근 실패 기록이다. 영상 제목·장면·대사·문서 목차를 추측해 작성하지 않는다.

## 독립적으로 구현한 범위

사용자가 직접 정한 ‘최대 4인에 맞는 최소 4직업’과 ‘같은 직업 중복 선택 금지’를 구현했다. 신규 수색대/공작대의 수치·스킬·외형은 이 프로젝트의 자체 설계이다. 기존 컷신에는 신규 주연의 대사와 도트 캐릭터만 보완했다. **제공된 영상에 근거한 컷신 UI·진행 형식 개편, 디비전 자료 기반 플레이 개편, 클래식 하위 문서 검토는 미완료다.**

## 접근을 위해 저장한 환경 설정

기존 npm/GitHub 네트워크 프리셋과 개발 문서 도메인을 보존하고 아래 도메인을 환경 설정 초안에 추가했다.

- `youtu.be`, `www.youtube.com`: 영상 링크와 페이지.
- `i.ytimg.com`: 영상 이미지/썸네일.
- `*.googlevideo.com`: 실제 영상 스트림.
- `namu.wiki`: 요청 문서와 해당 사이트의 하위 문서.

설정 초안 저장은 현재 실행 환경에 적용하는 동작이 아니다. 환경 설정에서 검토·저장 후 Publish가 필요하다. 현재 인스턴스의 정책이 바뀌지 않았다면 갱신한 환경에서 재시도해야 한다. 사이트 자체의 접근 제한이 남는 경우에도 실제 응답을 확인해 별도 보고해야 한다. 인증·봇 차단을 우회하지 않는다.

## 자료에 접근한 뒤 수행할 작업

1. 영상의 실제 장면을 확인하고 대화창 위치·초상화·텍스트 표시·카메라·장면 전환·입력/스킵 정책을 기록한다.
2. 디비전 본문에서 역할 분담·전투·목표·구간 구성을 확인한다.
3. 클래식 본문의 실제 하위 링크를 수집해 에피소드 0과 스토리 전환에 관련된 문서를 우선 검토하고 확인한 범위를 남긴다.
4. 확인한 일반적인 게임 방식과 연출 원칙을 이 프로젝트의 캐릭터·이야기·맵에 맞게 구현한다.
5. 현재 동기화 컷신·4직업 독점·모바일 가로 입력·에피소드별 티켓 규칙을 유지하며 브라우저 검사를 실행한다.
