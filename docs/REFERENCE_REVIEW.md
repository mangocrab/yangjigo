## 영상은 아직 실제 시청하지 못함

요청 영상: https://youtu.be/X6sYEVPqxzg

- 일반 watch·모바일·단축 주소와 공식 oEmbed는 이 환경에서 여전히 프록시 CONNECT 403으로 실패했다.
- 공식 `youtube-nocookie.com` 임베드 HTML은 200으로 열렸다. 최초 직접 플레이어 요청은 152-18로 실패했다.
- 브라우저 인증서 신뢰 오류를 확인한 뒤 TLS 검증을 유지하는 요청 클라이언트로 공식 임베드를 점검했다. 플레이어 메타데이터는 정상 응답했고 제목 **「좀비고 리부트 전 복습하자! : 좀비고 진격의 좀비 스토리」**, 채널 **Con PD**, 길이 **23:40**, 에피소드 0 챕터를 확인했다.
- 그러나 실제 `googlevideo.com` 스트림은 프록시 CONNECT 403으로 차단돼 재생 위치는 0:00에서 진행하지 못했다. 영상 프레임·음성·자막 내용은 확인하지 못했다. TLS 검증을 끄거나 인증/사이트 제한을 우회하지 않았다.

따라서 **이번 UI를 해당 영상의 실제 화면과 대조했다고 주장하지 않는다.** UI 개선은 읽은 문서의 진행 구조를 바탕으로 독립적으로 제작했다. 영상의 정확한 대화창 배치·컷 전환·카메라 타이밍 비교는 영상 파일, 주요 장면 캡처 또는 이 환경에서 재생 가능한 대체 자료가 있어야 마무리할 수 있다. 같은 설정 Publish를 반복하는 것은 확인된 해결책이 아니다.
