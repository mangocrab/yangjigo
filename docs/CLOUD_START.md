# 세종 봉쇄구역 클라우드 개발 시작

이 작업은 이미 격리된 환경이다. 기존 `/workspace/yangjigo`에서 작업하고 사용자 명시 요청 없이 Git worktree를 만들지 않는다. 먼저 README.md와 docs/PROGRESS.md, docs/ENVIRONMENT_RECOVERY.md를 읽고 기존 변경과 데이터는 보존한다.

## 소스 보존 상태

2026-10-19 재시작 시 원격 저장소의 브랜치 목록이 비어 있었고 이전 소스와 계정 DB가 없었다. 현재 v0.4 소스는 요구사항과 대화에서 다시 구현했다. 로컬 파일·로컬 커밋·환경 초안만으로 다음 작업 복원을 보장하지 않는다. 소스가 없으면 설치 재시도만 반복하지 말고 게시된 GitHub 커밋 또는 사용자가 보관한 소스 백업을 복원한다. 원격 푸시나 운영 배포는 자동 수행하지 않는다. `.wrangler` 계정 DB는 소스 백업과 별도다.

## 준비와 실행

Node.js 22.12 이상, npm을 사용한다. 검증 환경은 Node 24.19.0/npm 11.9.0, Phaser 4.2.1, Wrangler 4.151.0이다. 로컬 개발에는 Cloudflare 인증이 필요 없다. 비밀값을 출력하지 않는다. 명령은 `/workspace/yangjigo`에서 실행한다.

```bash
export npm_config_cache=/tmp/sejong-npm-cache
export XDG_CONFIG_HOME=/tmp/sejong-config
export WRANGLER_SEND_METRICS=false
```

의존성이 없거나 lockfile이 바뀌었으면 `npm ci --no-audit --no-fund`를 사용한다. `npm run db:migrate`로 로컬 D1의 0001~0003을 적용한다. 반복 적용은 안전하다. 기존 DB나 `.wrangler`를 삭제해 오류를 우회하지 않는다. 전체 재준비 검사 명령은 `bash scripts/setup.sh`다.

`npm run dev`는 타입 검사·Vite 빌드 뒤 0.0.0.0:8787에서 Worker/정적 파일/로컬 D1/SQLite DO를 함께 시작한다. 장기 실행 세션으로 유지하고 로그를 확인한다. 의존성과 파일이 남아 있어도 실행 프로세스·소켓은 재시작해야 한다. 기존 포트 점유 시 이 프로젝트 서버인지 확인해 재사용하며 관련 없는 프로세스를 종료하지 않는다. 클라이언트 수정 후 `npm run build`, 서버 소스는 Wrangler 감시를 사용한다.

루트 HTML이 게임 제목을 반환하고 비인증 `/api/me`가 401인지 내부 요청으로 확인한다. PID나 열린 포트만으로 준비 완료라 하지 않는다. 사용자용 루프백 미리보기 링크를 만들지 않는다.

## 기능과 검사

에피소드 0에는 작업대가 없다. 방에서 주연/직업을 선택하고 실제 플레이에서 돌 적중→개별 무기 수령으로 스킬을 해금한다. 시작·무기·구간 전환·엔딩 컷신은 접속 중인 전원이 확인할 때까지 서버 이동·공격·AI를 멈춘다. 평상시 메뉴와 NPC 대화의 개별 입력 차단과 구분한다. 프롤로그는 에피소드 0이며 교실→동관→운동장 3구간이다. 에피소드 1~4는 준비 데이터만 있고 선택 불가다. 이지/노말/하드, 노말 완주마다 해당 에피소드 하드 티켓 +1이다. 현재 기본 정책은 하드 입장 시 전원이 각자 1장 소모, 같은 입장의 체크포인트/처음부터 재도전은 추가 소모 없음이다. 한 명이라도 부족하면 모두 무차감이다. 난이도 변경은 전원의 준비를 해제한다.

상점은 실제 클리어 재화로 스킨을 구매하며 보유권·가격·잔액·중복 요청을 D1에서 검사한다. 장착은 다음 방 참가부터 적용한다. 에피소드별 진행·티켓·XP·업적은 프로필에서 확인한다. 보상은 마지막 탈출에만 지급하며 중복 지급하지 않는다. 기존 legacy 기록에는 하드 티켓을 소급 발급하지 않는다.

변경 범위에 맞게 `npm run build`, `npm test`, `npm run test:e2e`를 실행한다. SQLite 테스트는 Python 3, E2E는 Chromium이 필요하다. `/usr/bin/chromium`을 자동 사용하며 다른 경로는 PLAYWRIGHT_CHROMIUM_EXECUTABLE로 지정한다. 브라우저가 없으면 `npx playwright install chromium`으로 설치한다. 보안·TLS·패키지 무결성 검증을 끄지 않는다.

E2E는 8788 포트와 독립 임시 D1/DO에서 실제 계정을 만들어 사용하고 종료 시 정리한다. 개발 서버/DB를 재사용하지 않는다. 4인 노말·하드 완주, 전원 티켓 확인/차감, 구매·장착·프로필, 키보드/독립 멀티터치, 세로 차단, 실제 돌 던지기·직업 무기 획득·컷신·퍼즐 UI·작업대 차단·게임오버·체크포인트를 검사한다. 가입/로그인의 10분 30회 제한을 숨기거나 비활성화하지 않는다.

스마트폰 세로에서는 로그인부터 결과 화면까지 앱 전체를 비활성화한다. 회전·앱 전환·연결 종료 시 해당 사용자 입력을 해제한다. 메뉴나 한 사용자의 회전은 방 전체를 멈추지 않는다. 전원이 연결을 잃은 시간은 방어 임무 타이머에서 제외한다.

검증한 내용과 미완료 범위를 한국어로 docs/PROGRESS.md에 기록한다. 로컬 Chromium 에뮬레이션 통과만으로 iPhone/Android 실기기·Safari·공개 Cloudflare 검증을 주장하지 않는다. 원격 배포에는 실제 D1 ID·계정 권한·요금제 확인이 필요하다. 유료 리소스는 사용자 허락 없이 활성화하지 않는다. 환경 초안 저장은 Publish나 새 작업 복원 검증이 아니므로 이를 구분해 보고한다.
