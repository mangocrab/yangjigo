# 게임 설계 v0.4

실제 세종시를 배경 모티브로 사용한다. 학교·연구시설·인물·사건은 허구이며, 기존 게임의 그래픽·맵·대사·고유 표현을 복제하지 않는다. 초기 아트는 코드로 만든 32px 픽셀 텍스처다.

## 에피소드

| 번호 | 제목               | 상태              |
| ---- | ------------------ | ----------------- |
| 0    | 탈출 불가능한 학교 | 3구간 플레이 가능 |
| 1    | 버려진 도시        | 기획, 선택 불가   |
| 2    | 침묵하는 행정도시  | 기획, 선택 불가   |
| 3    | 금강의 마지막 길   | 기획, 선택 불가   |
| 4    | 봉쇄선 너머        | 기획, 선택 불가   |

에피소드 0은 감염 직후의 방송 컷신에서 시작한다. NPC의 안내로 이동·상호작용을 익힌 뒤 돌 던지기를 실제 감염자에게 세 번 적중시킨다. 퓨즈를 얻고 전원이 비상 장비함에서 자신의 무기를 수령한 뒤, 무기와 스킬 조작을 안내하는 컷신을 본다. 칠판 단서로 잠금장치를 연다. 전원이 출구로 모이면 동관으로 이동한다. 동관에서 안내를 듣고 발전기를 복구한 뒤 전원이 이동한다. 운동장에서 두 제어기를 켜고 12초간 버텨 정문을 열어 전원이 탈출한다. 티켓과 보상은 마지막 탈출 때 지급한다. 번호와 준비 여부는 `src/shared/rules.ts`의 에피소드 데이터에서 관리한다.

각 구간 진입 시 참가자의 HP·무기 획득·돌 적중 수·기존 자원을 체크포인트에 기록한다. 전멸 시 해당 상태로 복원하고 적·임무·문·타이머를 초기화한다. 처음부터 재시작도 가능하다. 구간 이동 시 최대 HP 이내에서 HP 35를 회복한다. 쓰러진 동료는 인접 상호작용이나 의무대 스킬로 일으킨다. 탈출은 전원 생존·접속·집결 조건을 요구한다.

## 직업과 주연

방에서 선택할 수 있는 주연은 한도윤(야구부 주장·선봉대)과 백해인(보건 동아리·의무대)이다. 같은 직업의 중복 선택은 허용한다. 도윤은 머리띠·짧은 머리·배트, 해인은 묶은 머리·응급 가방·구조용 신호총의 실루엣을 쓴다. 스킨은 의상 팔레트와 액세서리를 변경하며 직업·능력치에는 영향을 주지 않는다. 방향별 앞/뒤/측면과 걷기 2프레임을 32×32 도트로 생성한다.

무기 획득 전에는 공격력 14·사거리 3칸·간격 520ms의 돌 던지기만 가능하며 직업 스킬은 서버가 거부한다. 튜토리얼은 실제 적중을 검사하므로 빈 방향 공격만으로 완료되지 않는다. 미션 전 적중도 기록해 미리 적을 모두 처치했을 때 진행이 막히지 않도록 한다.

장비함은 공유되지만 무기는 각자 수령한다. 선봉대는 HP 140·배트 공격력 26·사거리 1·480ms, 밀치기와 방어를 쓴다. 의무대는 HP 100·신호총 공격력 18·사거리 2·520ms, 회복과 구조를 쓴다. 전원이 무기를 얻어야 다음 미션과 무기 획득 컷신이 시작된다. 에피소드 0의 모든 맵에서 작업대를 제거했으며 강화 API도 서버에서 차단한다. 향후 에피소드에 대비한 강화 로직만 남긴다.

## 컷신과 적 콘셉트

`src/shared/story.ts`에 시작/무기 획득/동관/운동장/엔딩 5장면의 장소·도트 배경·주연·대사를 정의한다. 전환은 서버가 장면 ID를 부여한다. 클라이언트는 대사를 넘겨 마지막에 확인 명령을 보내며 서버는 접속 중인 전원 확인 후 이동·공격·AI를 재개한다. 전원 확인 전 탈출 보상을 지급하지 않는다. 재접속은 현재 장면과 자신의 확인 상태를 이어받고, 체크포인트 재도전에는 해당 구간 도입 컷신이 다시 나온다. 메뉴·ESC로 컷신을 우회할 수 없다. 개별 NPC 대화와 평상시 메뉴는 본인 입력만 멈춘다.

| 감염자          | 외형                       | 기본 난이도 대비                                    |
| --------------- | -------------------------- | --------------------------------------------------- |
| 교복 감염자     | 교복·학생 가방·변색된 피부 | HP/이동/피해 기본값                                 |
| 체육복 감염자   | 체육복·머리띠·빠른 걸음    | HP ×0.75, 이동·공격 간격 ×0.7, 피해 ×0.8, 탐지 14칸 |
| 시설관리 감염자 | 안전모·작업복·공구         | HP ×1.7, 이동·공격 간격 ×1.45, 피해 ×1.5, 탐지 8칸  |

모든 적은 같은 서버 경로·장애물 규칙을 따른다. 방별 적 배치는 스테이지 데이터로 지정한다. 새로운 보스나 원거리 적은 아직 구현하지 않았다.

## 난이도와 성장

이지/노말/하드는 적 HP 52/78/117, 피해 8/12/18, 이동 간격 700/560/420ms, 공격 간격 1050/900/750ms를 사용한다. 보상은 각각 180XP·90C / 300XP·150C / 450XP·225C이다. 레벨은 `1+floor(누적 XP/300)`이며 직업 강화와 분리한다.

노말 완주마다 같은 에피소드의 하드 티켓을 1장 발급한다. 기본 정책은 입장 때 전원 1장씩 소모하며, 참가자 중 한 명이라도 부족하면 모두 소모하지 않는다. 같은 입장 안에서 재도전·처음부터 재시작은 무료이다. 이지·하드 완주는 티켓을 주지 않는다. 다음 에피소드로 티켓을 넘겨 쓸 수 없다. 에피소드별 클리어 횟수·최단 시간·티켓과 첫 클리어/하드 업적을 프로필에서 확인한다.

스킨은 기본 교복, 생존자, 탐험가, 특수 구조대 4종이다. 구매는 게임 내 재화만 사용하고 능력치에 영향을 주지 않는다. 장착은 다음 방 참가부터 적용한다.

## 입력과 모바일

이동은 상하좌우 1칸, 간격 140ms이며 대각선을 허용하지 않는다. 터치 조이스틱은 큰 축을 선택하고 데드존·히스테리시스를 적용한다. 이동/공격 포인터를 독립 관리하고 release·cancel·blur·앱 숨김·화면 회전 때 입력을 해제한다. 스마트폰 세로 화면은 앱 전체를 inert 처리하고 회전 안내만 표시한다. 화면 잠금 API가 실패해도 가로 플레이와 안내는 동작한다. 조작 크기·투명도·초기화는 브라우저 설정으로 저장한다. 자유 배치·유동 조이스틱·진동은 미구현이다.

에피소드 1~4의 실제 맵·보스·추가 직업·사운드·풍부한 대화 연출은 후속 콘텐츠로 남긴다.
